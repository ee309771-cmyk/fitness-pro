# 验证记录

这是实验性个人工具，不继承上游项目的动作识别准确率。

## 实施顺序

1. 工程、中文界面、上游许可及可复现构建。
2. 固定侧拍卧推：可见性、分段、计次与人工修正。
3. 本地模型推理、视频回放、关节叠加。
4. 参考动作逐次对比、本地历史、导出与手机验证。

每一阶段完成适用检查后分别推送到 `ee309771-cmyk/fitness-pro`。
验证记录须区分合成关键点、上游已有关键点、实际视频解码和手机实测。
未获得真实手机样片前，不宣称达到 90% 计次准确率或完成健身纠偏验证。

## 实机验收目标

- 至少 10 组人工标注的清晰侧拍卧推，9 组计次误差不超过 1 次。
- 两台实际手机（iPhone Safari、安卓 Chrome）分别验证导入、解码、取消、回放、保存。
- 出杠/回架、底部停顿、半程动作、遮挡、竖拍与不同朝向单独测试。
- 无可见关节不输出测量；手动修正须保留来源。

以上为后续验收目标，尚未完成。
