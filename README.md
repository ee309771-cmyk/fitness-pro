# Fitness Pro

手机本地的六类胸部动作复盘原型。中文界面，面向固定侧拍；视频、姿态推理和历史记录均留在浏览器中。

当前支持手动选择：平板杠铃卧推、上斜杠铃卧推、平板哑铃卧推、上斜哑铃推胸、器械推胸、俯卧撑。

## 已实现

- 导入训练视频，本机 MediaPipe Full 模型识别关节；CPU Worker 避免阻塞界面。
- 复用 WorkoutVision 的 WebCodecs / 播放解码与冻结帧检测，支持常见手机视频格式。
- 近侧肩肘腕跟踪、实验性计次、逐次骨架回放、角度曲线和幅度/节奏观察。
- 各动作独立拍摄指引、推举方向对应的腕肘偏移；俯卧撑增加可见肩髋踝投影夹角。
- 参考动作按六种类型隔离；上斜角度、握法及器械设置需人工确认一致。
- 手动修正次数、排除错误分段、手动设置每次开始/底部/结束。
- 导入参考视频或选取个人参考动作，逐次分阶段对齐，保留真实节奏差异。
- IndexedDB 本地复盘、可选保存本机原视频、JSON 报告导出。
- 标注清楚的合成演示，可先体验流程。合成参考不能用于评判实拍视频。

## 运行

需要 Node.js 22.12+ 和 pnpm 11：

```sh
pnpm install --frozen-lockfile
pnpm run prepare:assets
pnpm run dev
```

构建与检查：

```sh
pnpm test
pnpm run build
pnpm run preview
```

首次准备资源需下载 Google 官方模型（约 9.4 MB），脚本校验固定 SHA256，并复制匹配版本的 WASM。运行时资源由本站提供，不向姿态 API 上传视频。

生产环境使用 HTTPS；手机应访问部署网址，电脑上的 localhost 不等于手机上的 localhost。单视频最多 2 分钟、250 MB；不支持的编码建议转换为 MP4/H.264。清除浏览器数据会删除本地训练记录，请导出重要报告。

## 当前验证与限制

22 项自动检查通过，生产构建通过。自动计次仍为实验性结果，必须人工复核。

固定上游提交的两个公开侧拍关键点开发样本：7 次样本识别为 7 次；9 次样本识别为 4 次。后者仍有严重漏计，不能据此宣称动作准确率达标。这不是新视频端到端测试，也不是独立评测。详见 [验证记录](docs/VALIDATION.md)。

未完成真实 iPhone / 安卓设备验收；没有预置经授权且逐帧审核的专业标准示范。已提供公开教学链接及参考视频导入入口。画面中的肘角和手腕/肘位置差属于描述性指标，不是临床关节角度、实际受力或动作合格评分；不推断肩胛状态、伤病或隐藏关节。

本轮仅完成这六类胸部动作，等待用户提供的两段视频做端到端验证；暂不开发深蹲、硬拉和其他动作。六种类型共用实验性肘部周期算法，尚未完成六类真人视频准确率验证。实时语音纠错留待录后复盘可靠性验证后考虑。
